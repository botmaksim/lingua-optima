System Architecture

How the algorithms execute tasks

Task Generation Sequence

01 Learner or Teacher selects AI provider, model & parameters
↓
02 AI Broker queries Groq Llama 3.3 70B / BYOK model & fallback chain
↓
03 Sequence of exercises + answer keys compiled & sanitized
↓
04 System deploys task to learner dashboard
↓
05 Students execute → CAT adaptive testing & PostgreSQL metrics

OCR Recognition Pipeline

Learner uploads image of handwritten task
↓
In-memory Tesseract (tess4j) parses handwriting
↓
Gemini 2.5 Flash evaluates against answer key
↓
Instant feedback returned; image purged (Zero-Retention)

Security & Compliance

AI Ethics & Data Privacy

Zero-Retention OCR

When a student uploads a photo of their homework, the image is processed in RAM and immediately purged. We do not store biometric handwriting data.

Standardized Rubric Calibrations

Standardized CEFR prompts and multi-provider fallback chains (Groq ↔ Gemini) prevent grading bias and ensure objective, reproducible evaluation.

GDPR & Privacy By Design

2-step email verification via Gmail SMTP with Redis rate limiting, AES-256-GCM encrypted user API keys, in-memory JWT tokens, soft-delete group isolation, and complete right-to-be-forgotten cascade support.

Absolute Data Integrity

Our infrastructure ensures that personal language vulnerabilities are utilized strictly for algorithmic adaptation, never for unauthorized commercial profiling.
