# Conditionals 0, 1, 2
## Target CEFR: B1
### 1. Structural Formulas:
- **Zero Conditional (Universal Truths / Scientific Facts)**:
  - *If/When + Present Simple, Present Simple.*
  - *If water reaches 100°C, it boils.*
- **First Conditional (Real & Probable Future Conditions)**:
  - *If + Present Simple, will/won't + base verb.*
  - *If we sign the contract today, delivery will commence next Monday.*
- **Second Conditional (Hypothetical / Unreal Present or Future)**:
  - *If + Past Simple, would/could + base verb.*
  - *If I had more financial resources, I would launch a tech startup.*
  - Note: *If I were you* (subjunctive were for all persons).
