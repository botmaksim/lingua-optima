# Used to / Would
## Target CEFR: B1
### 1. Structural Form & Constraints:
- **Used to + base verb**:
  - Past repeated habits (*We used to spend summers by the coast*).
  - Past states / situations (*She used to have long hair; He used to live in Tokyo*).
- **Would + base verb**:
  - Past repeated actions / routines only (*Every Sunday, my grandfather would tell stories*).
  - **Crucial Rule**: *Would* CANNOT be used for past states (*He would be a teacher* is incorrect; must be *He used to be a teacher*).
