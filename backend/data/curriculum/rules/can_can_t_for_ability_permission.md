# Can / Can't for Ability & Permission
## Target CEFR: A1
### 1. Structural Form:
- Affirmative: Subject + can + base verb. (e.g., *I can swim.*)
- Negative: Subject + cannot / can't + base verb. (e.g., *She cannot drive.*)
- Question: Can + Subject + base verb? (e.g., *Can you help me?*)
### 2. Core Usage:
- Express physical/mental ability or ask/give permission.
### 3. Common Errors:
- Adding 'to' after can (*I can to swim* -> *I can swim*).
- Adding -s in 3rd person (*He cans swim* -> *He can swim*).
### 4. Exemplary Sentences:
- *She can speak three languages fluently.*
- *Can I open the window, please?*
- *They can't come to the party tonight.*
