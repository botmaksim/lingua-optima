# Wish / If Only
## Target CEFR: B2
### 1. Structural Nuances:
- **Regret about the Present**: *wish / if only + Past Simple* (*I wish I had more free time*).
- **Regret about the Past**: *wish / if only + Past Perfect* (*If only we had reserved tickets earlier!*).
- **Annoyance / Desire for someone else's behavior to change**: *wish + would + base verb* (*I wish you would stop interrupting the presentation*).
  - Note: Cannot say *I wish I would* (use *I wish I could*).
### 2. Emphatic Value:
- *If only* carries greater emotional resonance and distress than *I wish*.
