# Questions & Negatives Mixed (Be, Do, Can)
## Target CEFR: A1
### Integrated Challenge:
- Discerning when to form questions and negatives with the auxiliary 'do/does', modal 'can', or copula 'be'.
### Decision Matrix:
- Action verbs -> Do/Does (e.g., *Do you eat meat? I don't.*)
- State / Adjective / Identity -> Am/Is/Are (e.g., *Are you hungry? I am not.*)
- Ability / Permission -> Can (e.g., *Can you drive? I can't.*)
