# Relative Clauses (non-defining)
## Target CEFR: B2
### 1. Structural Rules:
- Enclosed by commas; provides extra, non-essential biographical or descriptive information.
- Pronoun 'that' CANNOT be used (use *who, which, whose, where, when*).
- Relative pronoun CANNOT be omitted, even if it is an object.
- Sentential relative clauses with *which*: Refers back to the entire preceding clause (*The proposal was rejected unanimously, which astonished the board*).
### 2. Exemplary Sentences:
- *Professor Evans, whose research revolutionized molecular biology, will chair the committee.*
- *The headquarters, which was built in 1920, will undergo comprehensive modernization.*
