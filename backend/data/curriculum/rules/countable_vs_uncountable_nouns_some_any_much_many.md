# Countable vs Uncountable Nouns (some, any, much, many)
## Target CEFR: A2
### 1. Structural Form & Quantifiers:
- **Countable** (apples, chairs, tickets):
  - *many*, *a few*, *a lot of*.
- **Uncountable** (water, information, advice, luggage, money):
  - *much*, *a little*, *a lot of*.
- **Some vs Any**:
  - *some*: affirmative sentences, polite requests/offers (*I have some questions. Would you like some water?*).
  - *any*: negatives and general questions (*I don't have any cash. Do you have any sugar?*).
### 2. Common Errors:
- Pluralizing uncountables (*informations, advices, furnitures*).
- Using *many* with uncountables (*many money* -> *much money*).
